Oqool Agent 0.3.4

Connects AI models — Oqool Cloud, Claude, ChatGPT, any MCP client — to your computer.

- One-line install: links this computer in the browser and keeps the agent running in the background.
- The whole computer by default; limit it with allowed folders and your own block list.
- Files, search, commands, live processes (REPL, ssh, servers), system processes, settings, local log.
- Updates itself on start.

**Linux / macOS**
```sh
curl -fsSL https://github.com/moaid15-hub/oqool-agent/releases/latest/download/install.sh | sh
```
**Windows — CMD**
```bat
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/moaid15-hub/oqool-agent/releases/latest/download/install.ps1 | iex"
```
**Windows — PowerShell**
```powershell
irm https://github.com/moaid15-hub/oqool-agent/releases/latest/download/install.ps1 | iex
```
